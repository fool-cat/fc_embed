# `fc_trans` 设计与实现说明

本文档对应以下代码:

- [fc_trans.h](./fc_trans.h)
- [fc_trans.c](./fc_trans.c)

## 1. 模块定位

`fc_trans` 是 `core/` 里一层“单物理通道上的多逻辑页传输”适配层。

它的目标不是做通用二进制协议封装，而是给日志、控制台文本、调试输出这类“可视化字符流”增加一个轻量分页标记，让同一条输出链路能够承载多个逻辑窗口的数据。

## 2. 当前实现方式

当前实现由两部分组成：

- `fc_sender_*` 负责在发送数据时插入分页切换标记
- `fc_receiver_*` 负责在接收侧识别标记并把数据分发到对应索引

默认分页标记格式定义在 [fc_trans.c](./fc_trans.c) 中，形如 `ESC[?;<index>m`，可支持 `0 ~ 9999` 的逻辑页编号。

## 3. 使用边界

这个模块更适合:

- 多窗口日志输出
- 调试串口复用
- 基于字符流的逻辑通道区分

不太适合:

- 纯二进制透明传输
- 对帧同步和碰撞容忍度很低的协议链路

头文件里已经明确标注“暂时建议不使用”，因此在正式项目里更适合作为特定场景下的辅助层，而不是基础通信协议层。
