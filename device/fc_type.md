# `fc_type` 设计与实现说明

本文档对应以下代码:

- [fc_type.h](./fc_type.h)

## 1. 模块定位

`fc_type` 是 `device/` 侧的公共基础头文件，用来统一设备层模块对“时间类型、时间获取、断言语义和原子语义入口”的依赖。

它本身不提供复杂算法，更像是设备层多个模块共享的一层最小抽象。

## 2. 当前提供的内容

[fc_type.h](./fc_type.h) 主要整理了这些约定:

- 统一引入标准整数和布尔类型
- 通过 `fc_time_t` 约定设备层时间类型
- 通过 `fc_get_ms()` / `fc_get_time()` 约定平台时间接口
- 通过 `fc_dev_assert()` 约定设备层断言入口
- 引入 [../core/fc_arch.h](../core/fc_arch.h) 作为原子/架构相关能力入口

## 3. 适用场景

这个头文件主要给以下模块做公共依赖:

- `fc_sig`
- `fc_sig_filter`
- `fc_stp_base`
- `fc_stp_curve`

如果项目需要替换时间来源、断言策略或底层架构适配，一般优先从这里做宏层重定义，而不是在各个设备模块里分别修改。
